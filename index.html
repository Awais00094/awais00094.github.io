Securing RISC-V Processors
before they reach silicon

I am a PhD researcher in the COMELEC department at Télécom Paris, working within the ANR SCAMA project. My research covers pre-silicon security validation, ISA-level mitigations, side-channel analysis and microarchitectural vulnerability assessment for RISC-V processors, combining gem5 simulation, machine learning and validation on real hardware such as the SiFive HiFive Premier P550.

Research

Projects

My work follows the processor security lifecycle. I find leakage and fault paths early in simulation, design mitigations at the ISA level, and then confirm both attacks and defenses on commercial RISC-V silicon.

Unfenced · Atomic Guards
HASP @ MICRO 2026

Lock-free, ISA-level Spectre V1/V2 mitigations that use RISC-V lr.w.aq/sc.w.rl instead of serializing fences. On the SiFive HiFive Premier P550, a batched variant (N=16) is 2.8× faster than fence-based protection with a 0% store-conditional failure rate.

TRAPHALT
SECRYPT 2026

A privilege-boundary attack in which crafted illegal instructions from user mode travel through kernel trap handling into OpenSBI's unhandled-fault path (sbi_trap_error() → sbi_hart_hang()), persistently halting a RISC-V hart. Validated on the P550 via JTAG/OpenOCD.

RV-Sec5
Best Paper · AISC 2026 · Pragmatic Cybersecurity

Targeted ISA-level instrumentation in gem5 for pre-silicon RISC-V security evaluation. It exposes security-relevant microarchitectural events at instruction granularity. The journal version adds a full instrumentation-overhead analysis.

ML Detection of Speculative Leakage
IOLTS 2026 · TDMR extension in progress

Combines static code features (AST/CFG/DFG) with gem5 runtime signals to detect Spectre-variant leakage, using supervised models (XGBoost, ~97% accuracy) and unsupervised ones (HDBSCAN, Isolation Forest). ISA-level masking wrappers on the P550 cost only 1.6% runtime overhead. The journal extension explores graph-based learning on CFG/DFG.

Methodology
1
Model & instrument

Expose leakage sources in gem5 (O3 pipeline, caches, predictors) with ISA-level instrumentation.

2
Detect & attribute

Use machine learning on static and runtime features to flag vulnerable code patterns and attack behaviors.

3
Mitigate at the ISA

Design lightweight, deployable mitigations such as atomic guards and masking wrappers.

4
Validate on silicon

Confirm attacks and measure overhead on commercial RISC-V hardware (SiFive HiFive Premier P550).

Emerging Directions
  • Post-quantum cryptography on RISC-V: evaluating ISA extensions for ML-KEM (CRYSTALS-Kyber, FIPS 203) acceleration in gem5.
  • Timer-free cache channels: instruction-cache attacks on RISC-V and ARM without high-resolution timers.
  • FPGA power side channels: ring-oscillator sensors against TrustZone Secure World on Zynq platforms.
  • Neuromorphic hardware: side-channel analysis of emerging compute paradigms.
